# Симулятор мозга C. elegans с модуляцией

## Что было сделано

На основе проекта [OpenWorm Analysis Toolbox](https://github.com/openworm/open-worm-analysis-toolbox) создан симулятор нейронной сети C. elegans со следующими улучшениями:

### Улучшения:
- ✅ **+10 нейронов** (оригинально 302 → теперь 312)
- ✅ **+20+ синаптических связей** 
- ✅ **Модуляция мозга** - возможность изменять возбудимость сети
- ✅ **Кроссплатформенность** - работает на Windows, Linux и macOS
- ✅ **macOS .pkg файл** - установщик для Mac

## Структура сети

| Компонент | Количество | Описание |
|-----------|------------|----------|
| Сенсорные нейроны | 99 | Обработка входных сигналов |
| Интернейроны | 132 | Интеграция сигналов |
| Моторные нейроны | 80 | Управление выходом |
| Модуляторные нейроны | 1 | Глобальная модуляция |
| **Всего нейронов** | **312** | **+10 к оригиналу** |
| Химические синапсы | ~1100 | Нейромедиаторные |
| Электрические синапсы | ~330 | Щелевые контакты |
| **Всего синапсов** | **~1450** | **+20+ к базе** |

## Установка и запуск

### Windows

```bash
# Установите Python 3.7+ с python.org
pip install numpy
python c_elegans_brain_sim.py
```

### Linux

```bash
# Установите зависимости
sudo apt-get install python3 python3-numpy  # Debian/Ubuntu

# Запустите симуляцию
python3 c_elegans_brain_sim.py
```

### macOS

#### Вариант 1: Прямой запуск
```bash
brew install python3
pip3 install numpy
python3 c_elegans_brain_sim.py
```

#### Вариант 2: Создать .pkg установщик
```bash
chmod +x create_pkg.sh
./create_pkg.sh

# Будет создан файл C_Elegans_Brain_Simulator.pkg
# Дважды кликните для установки или:
sudo installer -pkg C_Elegans_Brain_Simulator.pkg -target /
```

## Режимы модуляции

Симуляция показывает влияние нейромодуляции на активность сети:

| Уровень модуляции | Частота спайков | Эффект |
|-------------------|-----------------|--------|
| 0.5x | Низкая | Сниженная возбудимость |
| 1.0x | Нормальная | Базовая активность |
| 1.5x | Повышенная | Увеличенная отзывчивость |
| 2.0x | Высокая | Гипервозбудимое состояние |

## Пример использования в коде

```python
from c_elegans_brain_sim import CElegansBrain

# Создание мозга с модуляцией
brain = CElegansBrain(modulation_level=1.0)

# Применение модуляции (1.5 = повышенная возбудимость)
brain.apply_modulation(1.5)

# Запуск симуляции
results = brain.run_simulation(steps=1000)

# Статистика
stats = brain.get_network_statistics()
print(f"Нейронов: {stats['total_neurons']}")
print(f"Синапсов: {stats['total_synapses']}")
```
