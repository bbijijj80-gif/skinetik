# C. elegans Full Biophysical Simulation

Научно обоснованная симуляция нервной системы и поведения *Caenorhabditis elegans*.

## 🔬 Научные особенности

### 1. Реальный коннектом
- Данные из White et al. (1986) и Cook et al. (2019)
- Химические и электрические синапсы
- Учет количества синапсов между нейронами
- Рецепторная специфика (ACh, GABA, Glu, серотонин, дофамин)

### 2. Биофизика нейронов
- Специфичные ионные каналы C. elegans:
  - **EGL-19** (CaV1) - деполяризация
  - **UNC-2** (CaV2) - высвобождение медиатора
  - **SLO-1** - кальций-зависимые K⁺ каналы
  - **UNC-8/DEL-1** - механочувствительность
  - **TAX-2/TAX-4** - хемосенсорная трансдукция
- Интеграция Рунге-Кутты 4-го порядка
- Температурная компенсация (Q10)

### 3. Внутриклеточная динамика
- Вторичные мессенджеры (cAMP, IP3, DAG, Ca²⁺)
- G-белковая сигнализация (ODR-3, GPA-3)
- Кальциевые волны и буферирование

### 4. Синаптическая пластичность
- STDP (Spike-Timing-Dependent Plasticity)
- Гомеостатическая регуляция возбудимости

### 5. Модель мышц Хилла
- Сила-скорость зависимость
- Сила-длина зависимость
- Кальциевая активация
- Вязкое демпфирование

### 6. Биофизика тела
- Масса-пружина-демпфер система
- Трение о субстрат
- Гидроскелетное давление

### 7. Сенсорная трансдукция
- Хемотаксис (AWC, ASE нейроны)
- Тактильная чувствительность (ALM, AVM, PVM)
- Нелинейное преобразование стимулов

### 8. Валидация
- Сравнение с экспериментальными данными
- Скорость движения (~0.2 мм/с)
- Частота изгибов (~0.4 Гц)
- Частота спайков

## 🧬 Режимы мутантов

- **Wildtype** - нормальное поведение
- **unc-2_null** - паралич (сниженная скорость)
- **slo-1_null** - гиперактивность
- **egl-19_null** - летальный (нет движения)

## 📊 Визуализация

### Левая панель
- Червь с сегментированным телом
- Объекты среды (еда, стены, опасность)

### Правая панель
- Нейронная сеть с цветовым кодированием:
  - 🟢 Зеленый - сенсорные нейроны
  - 🔵 Синий - интернейроны
  - 🔴 Красный - моторные нейроны
- Яркость = активность нейрона
- Типы синапсов:
  - 🟢 Зеленый - возбуждающие (ACh, Glu)
  - 🔴 Красный - тормозящие (GABA)
  - 🟣 Фиолетовый - модуляторные
  - 🔵 Голубой - электрические

## 📈 Валидационные метрики

Симуляция в реальном времени показывает:
- **Speed** - скорость движения (мм/с), референс: 0.2
- **Frequency** - частота изгибов (Гц), референс: 0.4
- **Avg Firing Rate** - средняя частота спайков (Гц)

## ⚠️ Ограничения

Несмотря на высокую степень биофизической детализации, модель имеет ограничения:
- Не все 302 нейрона включены (демо-фрагмент)
- Упрощенная кинетика некоторых каналов
- Отсутствует полная экспрессия генов
- Нет долгосрочной адаптации (часы-дни)

Для полноценных исследований рекомендуется использование специализированных симуляторов (NEURON, Brian2) с полными базами данных.
